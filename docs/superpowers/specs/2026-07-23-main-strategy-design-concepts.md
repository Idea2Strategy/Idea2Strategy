# 메인·전략 디자인 시안 비교

## 목적

기존 균형형 UI를 바로 교체하지 않고, 메인 페이지와 전략 페이지의 시각 언어 및 정보 구조를 비교할 수 있는 독립 디자인 랩을 제공한다. 사용자가 한 방향을 고르면 선택된 구조를 실제 제품 화면에 확장한다.

## 공통 원칙

- 텍스트 설명보다 상태, 수치, 다음 행동을 먼저 보여준다.
- 하나의 화면에서 강조색은 한 계열만 사용한다.
- 메인 페이지는 자산 흐름, 실행 중인 봇, 최근 전략, Competition 상태를 짧게 요약한다.
- 전략 페이지는 검색, 상태 확인, 새 전략 생성, 기존 전략 재진입에 집중한다.
- 블록 라이브러리는 전략 목록 밖에 노출하지 않는다.
- 전체 / 준비 완료 / 미완성 상태는 큰 카드가 아닌 작은 필터나 요약 수치로 표현한다.
- 데스크톱과 모바일에서 정보 우선순위가 유지되도록 반응형으로 구성한다.

## 시안 A — Atlas Editorial

- 밝은 중성 배경과 짙은 청록색을 사용하는 편집형 대시보드
- 항상 접힌 아이콘 사이드바
- 큰 자산 흐름 카드와 선형 전략 목록
- 현재 제품과 연결하기 가장 쉬우며, 정보 밀도와 여백의 균형을 우선한다.

## 시안 B — Flow Canvas

- 따뜻한 회색과 옅은 청록 그라데이션을 사용하는 캔버스형 화면
- 상단 플로팅 내비게이션
- 메인은 비대칭 벤토, 전략은 큰 갤러리 카드
- 초보 사용자에게 부드럽고 친근한 인상을 주며 전략 탐색을 시각적으로 만든다.
- 홈, 전략, 봇, 백테스트, Competition, 전략 생성까지 같은 부드러운 표면과 여백 규칙을 적용한다.

## 시안 C — Signal Studio

- 차콜 배경과 라임 단일 강조색을 사용하는 분석 스튜디오
- 수평 내비게이션과 테이블 중심 전략 데스크
- 터미널 문법은 사용하지 않되 높은 정보 밀도와 강한 대비를 제공한다.
- 적극적인 투자자나 반복적으로 상태를 확인하는 사용자에게 적합하다.
- 홈, 전략, 봇, 백테스트, Competition, 전략 생성까지 같은 고밀도 규칙을 적용한다.

## 시안 D — Ledger Mono

- 아이보리 종이색, 강한 흑백 대비, 얇은 구분선을 사용하는 편집·장부형 화면
- 번호가 붙은 좌측 텍스트 내비게이션
- 메인은 일간 운용 보고서, 전략은 선형 등록부 형태
- 카드 중심 화면을 피하고 수치와 문장을 차분하게 비교하려는 사용자에게 적합하다.

## 시안 E — Orbit Glass

- 짙은 남색 공간과 반투명 표면, 원형 궤도 시각화를 사용하는 글래스형 화면
- 상단 플로팅 내비게이션과 시각적 전략 카드
- 메인은 운용 상태를 중심 궤도로 표현하고, 전략은 개별 시스템처럼 분리한다.
- 기술적이지만 터미널처럼 보이지 않는 미래적인 방향이다.
- 홈, 전략, 봇, 백테스트, Competition, 전략 생성까지 같은 글래스 표면과 색상 규칙을 적용한다.

## 시안 F — Core Interface

- MengTo `high-contrast-skeuomorphic-clean` 데모의 실제 구조를 기준으로 다시 설계한 고대비 클린 인터페이스
- 밝은 회색 외부 배경 위에 깊은 흑연색 앱 셸을 놓고, 얇은 링과 절제된 인셋 그림자로 표면 깊이를 만든다.
- 눌린 캡슐 내비게이션, 낮은 채도의 모듈 카드, 작은 상태 램프, 단일 강조색을 사용한다.
- 메인은 Timeline, Messages, Pending Actions, Active Market, Vitals 모듈로 운용 상태를 묶는다.
- 전략은 동일한 셸 안에서 요약 수치와 선형 목록을 제공한다.
- F는 비교 목적에 맞게 홈과 전략 페이지만 제공한다.

## B·C·E 확장 화면 규칙

- 봇은 개인용과 대회 참여로 전환할 수 있다. 대회 참여 화면은 대회별 순위 그룹으로 표현한다.
- 백테스트는 전략과 S&P 500 비교 차트를 중심에 두고, 3개월·6개월·1년·3년 기간과 주요 위기 구간을 선택할 수 있다.
- Competition은 공식 대회를 먼저 강조하고, 일반 대회는 검색 가능한 목록으로 제공한다.
- 전략 생성은 Basic, Pro, 기존 전략 가져오기로 시작한다.
- 종목을 먼저 선택한 뒤 종목 섹션 안에서 `매수 전략 · 필수`, `매도 전략 · 선택`을 설정한다.
- 여러 종목을 선택하면 동일 비중으로 운용한다.

## 비교 방법

- 경로: `/concepts`
- 상단 A–F 탭으로 시안을 전환한다.
- 메인/전략 탭으로 같은 디자인 언어의 두 핵심 페이지를 비교한다.
- 각 시안은 독립적인 색상 선택을 유지한다.
  - Atlas: Mint / Ocean / Coral
  - Flow: Sage / Lavender / Apricot
  - Signal: Dark Lime / Light Mint / Light Blue
  - Ledger: Red Ink / Cobalt / Forest
  - Orbit: Cyan / Violet / Solar
  - Core Interface: Cyan / Violet / Amber
- 전략 검색은 이름과 종목을 기준으로 실제 필터링된다.
- B, C, E의 제품 내비게이션은 봇, 백테스트, Competition 화면으로 실제 이동한다.
- B, C, E의 새 전략 버튼은 전략 생성 화면으로 이동하며 종목·모드·매도 조건 선택이 동작한다.

## 테이블 규칙

- Atlas 전략 목록은 전략명, 상태, 백테스트, 최근 수정, 이동의 5개 열을 사용한다.
- 상태 점과 전략명은 첫 번째 셀 안에 함께 배치해 나머지 열을 밀지 않는다.
- 좁은 화면에서는 전략명, 백테스트, 이동만 남기고 보조 열을 숨긴다.

## 선택 이후

선택된 시안의 내비게이션, 타이포그래피, 간격, 카드 규칙을 제품의 균형형 디자인 시스템으로 승격한다. 선택되지 않은 시안은 제품 코드에 확장하지 않는다.

## 선택 결과

- 2026-07-23: 사용자가 C안 `Signal Studio`를 현재 개발 중인 균형형 UI의 시각 기준으로 선택했다.
- 기존 접힌 사이드바, 화면 내용, 라우트, 검색·필터·편집 상호작용은 유지한다.
- 전략, 봇, 백테스트, Competition, 계정, 관리자, Basic/Pro 편집기에 차콜 표면, 라임 단일 강조색, 얇은 구분선, 고밀도 마이크로 라벨을 적용한다.
- 기본 테마는 Signal Studio의 다크 모드이며 기존 테마 전환 기능은 유지한다.
- 터미널형과 `/concepts` 비교 화면은 이 승격 작업의 변경 대상이 아니다.
