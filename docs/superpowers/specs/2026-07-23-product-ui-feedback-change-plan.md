# 제품 UI 피드백 변경 계획

## 문서 상태

- 2026-07-23 회의 피드백을 구현 가능한 화면 변경 단위로 정리한 제안서다.
- 현재 승인된 `specs/`와 `contracts/`는 수정하지 않는다.
- 기존 균형형 프로토타입을 우선 대상으로 하며, 공통 내비게이션 규칙은 모든 화면에 적용한다.
- 제품 의미가 달라지는 항목은 제품 승인 후 정식 사양으로 승격한다.

## 현재 프로토타입 반영 상태

이번 구현에서 다음 항목을 우선 반영했다.

- 전역 시장 지수와 `MARKET OPEN` 제거
- 사용자 관심종목 및 최근 알림 우측 상단 팝오버
- 사이드바 알림 제거
- `입력 필요 → 미완성`
- 전략 행 복사 제거 및 생성 과정의 기존 전략 가져오기
- 전략 홈의 블록 검색, 블록 패널, 연결 블록 칩, 블록 수 표시 제거
- Competition 공식 대회 카드, 검색·점수 방식·참여 인원 필터, 펼침형 봇 순위

블록은 전략을 실제로 만드는 Basic 편집기 안에서만 제공한다. 봇·종목·전략 계층, 편집기 전체 화면화, 주문 파티션, 백테스트 차트 개편은 후속 구현 단계로 유지한다.

## 목표

1. 모든 화면의 전역 UI를 단순화한다.
2. 전략 작성의 기본 구조를 `봇 > 종목 > 매수/매도 전략`으로 명확히 한다.
3. 주문과 백테스트에서 생성된 로그를 차트와 사건 흐름으로 탐색할 수 있게 한다.
4. 개인 봇과 대회 참여 봇, 공식 대회와 일반 대회를 분명히 구분한다.
5. 설명 텍스트는 줄이고 중요한 단어와 숫자만 빠르게 읽히게 한다.

## 한눈에 보는 변경사항

| 영역 | 현재 | 변경 |
| --- | --- | --- |
| 상단 바 | 고정 시장 지수와 시장 상태 표시 | 전역 시장 상태 제거, 사용자 설정 종목을 여는 작은 관심종목 버튼/팝오버 제공 |
| 알림 | 사이드바 메뉴 | 우측 상단 알림 버튼과 팝오버로 이동 |
| 상태 문구 | `입력 필요` | 모든 화면에서 `미완성`으로 통일 |
| 전략 재사용 | 전략 행의 `복사` | `새 전략` 생성 과정의 `기존 전략 가져오기`로 이동 |
| 전략 홈 블록 | 검색·추가 가능한 블록 패널 | 완전히 제거하고 Basic 편집기 내부에서만 제공 |
| 전략 구조 | 전략 중심 목록 | `봇 > 종목 그룹 > 종목 섹션 > 매수/매도 전략` 계층 |
| 종목 선택 | 별도 구조 없음 | 종목 선택 시 종목별 섹션 생성, 여러 종목은 동일 비율 배분 |
| Basic 편집기 | 중앙 카드 안에 블록, 호버 시 레이아웃 변화 | 전체 화면 캔버스와 플로팅 패널, 설명은 위치를 밀지 않는 오버레이 |
| 전략 필수 조건 | 매수/매도 그룹이 모두 존재 | 매수 전략 필수, 매도 전략 선택 |
| 봇 | 단일 봇 목록 | 개인용 / 대회 참여 탭, 대회별 접이식 순위 목록 |
| 주문 기록 | 요약 상태 중심 | 후보 생성 → 신청/거절 → 체결/실패 사건 흐름과 파티션별 차트 |
| 백테스트 | 요약 카드 중심 | 별도 차트 중심 화면, S&P 500 비교, 기간 사건과 로그 탐색 |
| 대회방 | 카드/순위 중심 | 공식 대회 최대 6개 상단 고정, 일반 대회 검색·필터 리스트 |
| 전략 설명 | 동일한 텍스트 굵기 | `1분봉`, 지표명, 연산자, 숫자와 비율을 굵게 표시 |

## 1. 공통 셸과 내비게이션

### 상단 바

- 모든 페이지에서 `MARKET OPEN`, S&P 500, NASDAQ, VIX처럼 고정 노출되는 시장 상태 영역을 제거한다.
- 우측 상단에는 사용자가 설정한 종목 추이를 여는 `관심종목` 버튼을 둔다.
- 버튼을 누르면 팝오버가 열리고 다음을 제공한다.
  - 종목 검색 및 추가
  - 종목 삭제와 순서 변경
  - 현재가, 등락률, 작은 스파크라인
  - 표시 종목이 없을 때의 설정 유도
- 관심종목은 사용자가 열었을 때만 상세 정보를 보여 주며 페이지 본문을 밀지 않는다.

### 알림

- 사이드바의 `알림` 메뉴를 제거한다.
- 우측 상단에 읽지 않은 개수를 포함한 알림 버튼을 배치한다.
- 팝오버에서는 최근 알림, 읽음 처리, 전체 알림 보기를 제공한다.
- 중요한 운영 알림은 색상만으로 구분하지 않고 아이콘과 상태명을 함께 표시한다.

### 용어

- 데이터와 화면에서 `입력 필요`를 `미완성`으로 변경한다.
- 필터의 `확인 필요`는 여러 원인을 묶는 상위 분류로 유지할 수 있지만, 전략 자체 상태는 `미완성`으로 표시한다.

## 2. 전략 목록과 생성 흐름

### 복사 제거

- 전략 행의 복사 버튼을 제거한다.
- `새 전략`을 누르면 다음 두 시작 방식을 먼저 보여 준다.
  1. `빈 전략 만들기`
  2. `기존 전략 가져오기`
- `기존 전략 가져오기`에서는 검색, Basic/Pro 필터, 원본 미리보기를 제공한다.
- 가져온 결과는 원본과 연결되지 않은 새로운 초안으로 생성하며 원본은 변경하지 않는다.
- 가져오기 범위가 `구조만`인지 `설정값 포함`인지는 구현 전에 제품 결정을 확정한다.

### 전략 목록 표시

- 각 전략 행은 이름, 모드, 완성 상태, 연결 종목 수, 매수/매도 구성 여부를 보여 준다.
- `미완성`의 원인은 행을 펼치거나 상세 패널에서 짧은 체크리스트로 보여 준다.
- 전략의 핵심 문장에서는 지표명, 시간 단위, 숫자, 비율을 굵게 표시한다.

## 3. 봇·종목·전략 계층

### 제안 구조

```text
봇
└─ 종목 그룹
   ├─ AAPL 섹션
   │  ├─ 매수 전략 (필수)
   │  └─ 매도 전략 (선택)
   └─ MSFT 섹션
      ├─ 매수 전략 (필수)
      └─ 매도 전략 (선택)
```

### 생성 규칙

- 종목 블록이 없으면 전략 블록을 추가할 수 없다.
- 종목을 한 개 선택하면 한 개의 종목 섹션을 생성한다.
- 여러 종목을 선택하면 종목별 섹션을 동시에 생성한다.
- 여러 종목의 기본 투자 비율은 `1 / 선택 종목 수`로 동일 배분한다.
- 섹션마다 매수 전략은 반드시 하나 이상 있어야 한다.
- 매도 전략은 없어도 저장할 수 있다.
- 매도 전략이 없을 때 포지션 종료 방식이 무엇인지는 별도 제품 규칙으로 확정해야 한다.
- 종목 삭제 시 연결된 전략을 즉시 삭제하지 않고 이동 또는 삭제 선택을 요구한다.

### 화면 구성

- 왼쪽: 봇과 종목 그룹의 계층 탐색기
- 중앙: 선택한 종목 섹션의 전략 캔버스
- 오른쪽: 선택한 종목/전략/블록의 상세 설정
- 종목 그룹 헤더에는 선택 종목 수와 동일 배분 비율만 간결하게 표시한다.

## 4. Basic 및 Pro 편집 화면

### 전체 화면 캔버스

- 편집기 배경을 페이지 본문 전체로 확대한다.
- 블록 팔레트, 종목 계층, 상세 설정은 캔버스 위에 떠 있는 플로팅 패널로 배치한다.
- 패널은 접기, 다시 열기, 화면 가장자리 고정을 지원한다.
- 캔버스 이동과 확대/축소 영역을 패널이 가리지 않도록 안전 여백을 둔다.

### 호버 동작

- 블록에 마우스를 올려도 블록이나 주변 요소의 위치와 크기는 변하지 않는다.
- 설명은 고정 레이어의 툴팁 또는 옆 패널에서 표시한다.
- 설명이 화면 밖으로 나가면 반대 방향으로 배치한다.
- 키보드 초점에서도 동일한 설명을 확인할 수 있다.
- 모바일과 터치 환경에서는 호버 대신 선택 후 상세 패널을 사용한다.

### 설명 문장

- 문장 전체를 굵게 하지 않는다.
- 다음 토큰만 굵게 처리한다.
  - 시간 단위: `1분봉`
  - 지표와 필드: `RSI`, `거래량`
  - 비교 연산: `30 미만`, `70 초과`
  - 주문과 배분: `매수 후보`, `25%`

## 5. 봇 화면

### 분류

- 상단에 `개인용`과 `대회 참여` 탭을 둔다.
- 개인용 탭은 사용자의 독립 봇을 상태별로 보여 준다.
- 대회 참여 탭은 봇을 대회방 단위로 묶는다.

### 대회 참여 봇

- 대회 블록을 누르면 내부의 참여 봇 목록이 펼쳐진다.
- 봇은 현재 순위를 기준으로 기본 정렬한다.
- 각 행에는 순위, 봇 이름, 점수, 수익률, 주요 상태를 표시한다.
- 실행 중단이나 평가 실패처럼 조치가 필요한 상태를 목록 상단에 별도로 표시한다.

## 6. 주문 사건과 파티션 차트

### 주문 사건 모델

화면에서는 다음 흐름을 시간순으로 구분한다.

1. 매수/매도 주문 후보 생성
2. 주문 신청 또는 정책에 의한 거절
3. 주문 체결 또는 실패

- 후보는 생성됐지만 유효성 검사에서 탈락해 주문을 신청하지 않은 경우도 독립 사건으로 남긴다.
- 이는 사용자의 직접 주문 기능이 아니라 잠긴 전략이 만든 주문 과정의 조회 화면이다.

### 파티션

- 차트는 종목 탭이 아니라 사건 파티션을 기준으로 전환한다.
- 기본 파티션:
  - `후보`
  - `신청·거절`
  - `체결·실패`
- 파티션을 누르면 같은 기간 차트 위에 해당 사건만 강조한다.
- 매수/매도, 성공/실패는 색상뿐 아니라 아이콘, 선 모양, 레이블로도 구분한다.

### 색상 방식

- `한국식`과 `미국식` 색상 프리셋을 설정에서 선택할 수 있도록 설계한다.
- 색상 의미는 설정 화면과 차트 범례에 명시한다.
- 현재 승인된 1차 시장 범위는 미국 종목이므로 한국식 프리셋은 표시 방식 옵션으로만 제안한다.
- 한국 시장 종목 지원으로 확장하는 것은 현재의 미국시장 전용 정책과 충돌하므로 별도 제품 승인 없이는 구현하지 않는다.

## 7. 백테스트

### 별도 차트 중심 화면

- 백테스트를 독립 페이지로 유지하고 차트를 가장 큰 시각 요소로 둔다.
- 전략 누적 성과와 S&P 500을 같은 기간, 같은 기준점에서 비교한다.
- 수익률만이 아니라 낙폭과 변동 구간도 함께 확인할 수 있게 한다.

### 기간과 사건 탐색

- 경제 위기, 코로나19 같은 주요 기간을 프리셋으로 제공한다.
- 사용자는 기간 확대/축소, 구간 선택, 이전/다음 사건 이동을 할 수 있다.
- 프리셋은 분석 편의를 위한 기간 표시이며 성과를 보장하거나 추천하지 않는다.

### 로그 활용

- 차트 아래에 주문 사건 로그를 시간순으로 연결한다.
- 차트의 한 점을 선택하면 해당 시점의 후보, 거절, 체결, 실패 로그를 보여 준다.
- 로그 필터:
  - 종목
  - 사건 파티션
  - 매수/매도
  - 성공/실패
  - 경고 수준
- 로그 행을 선택하면 차트의 해당 시점과 파티션을 강조한다.

## 8. 대회방

### 공식 대회

- 공식 대회는 상단에 단순 카드 형태로 고정한다.
- 최대 6개 내외만 노출하고 핵심 정보만 보여 준다.
  - 대회명
  - 상태
  - 종료까지 남은 시간
  - 참여 인원

### 일반 대회 탐색

- 공식 대회 아래는 리스트뷰를 사용한다.
- 검색과 다음 필터를 제공한다.
  - 모집/진행/종료 상태
  - 점수 산정 방식
  - 참여 인원 구간
  - 시작일과 종료일
- 정렬은 추천이 아니라 명시적인 기준으로 제공한다.
  - 최신순
  - 참여 인원순
  - 종료 임박순

## 제품 결정이 필요한 항목

| 결정 | 영향 | 권장안 |

## 구현 순서

### 0단계 — 제품 의미 확정

- 봇·종목·전략 계층 승인
- 매도 전략 없는 경우의 종료 정책 확정
- 가져오기 범위 확정
- 주문 사건 용어와 상태 전이 확정
- 색상 프리셋과 실제 지원 시장의 경계 확정

### 1단계 — 공통 셸

- 전역 시장 상태 제거
- 관심종목 팝오버
- 알림 우측 상단 이동
- `입력 필요 → 미완성`

### 2단계 — 전략 목록과 생성

- 행 복사 제거
- 생성 시 기존 전략 가져오기
- 종목 선택 및 동일 배분 요약
- 종목별 매수 필수/매도 선택 구조

### 3단계 — 편집기

- 전체 화면 캔버스
- 플로팅 팔레트와 상세 패널
- 레이아웃이 움직이지 않는 블록 설명
- 중요 단어와 숫자 강조

### 4단계 — 봇과 대회방

- 개인용/대회 참여 봇 분리
- 대회별 접이식 순위 봇 목록
- 공식 대회와 일반 대회 탐색 분리

### 5단계 — 주문과 백테스트

- 주문 사건 파티션
- 파티션 기반 차트
- S&P 500 비교
- 사건 기간 프리셋과 로그 연동

## 테스트 및 완료 조건

### 공통 셸

- 어느 페이지에서도 기본 시장 상태 티커가 나타나지 않는다.
- 관심종목 추가, 삭제, 순서 변경이 목업 상태에서 동작한다.
- 알림 버튼과 읽지 않은 개수가 우측 상단에 표시되고 사이드바에는 알림이 없다.
- `입력 필요` 문자열이 사용자 화면에 남아 있지 않다.

### 전략

- 복사 버튼이 없고 새 전략 생성 과정에서만 기존 전략을 가져올 수 있다.
- 종목 없이 전략을 추가할 수 없다.
- 두 종목 선택 시 두 섹션과 50%/50% 기본 배분이 생성된다.
- 매수 전략이 없으면 완료할 수 없고 매도 전략이 없어도 초안 저장은 가능하다.
- 블록 호버와 키보드 초점에서 주변 블록 위치가 변하지 않는다.

### 봇과 대회

- 개인용/대회 참여 전환이 동작한다.
- 대회를 펼치면 봇이 순위순으로 표시된다.
- 공식 대회와 일반 대회 리스트가 분리된다.
- 일반 대회 검색, 필터, 정렬 조합이 동작한다.

### 주문과 백테스트

- 후보, 검증 탈락, 신청 거절, 체결, 실패를 서로 다른 사건으로 조회할 수 있다.
- 파티션 선택이 차트와 로그에 동시에 반영된다.
- 색상을 제거해도 레이블과 아이콘으로 사건을 구분할 수 있다.
- 전략 성과와 S&P 500이 동일 기간과 기준점으로 비교된다.
- 주요 기간 프리셋과 로그에서 차트 시점으로 이동할 수 있다.

## 범위 밖

- 한국 시장 종목과 원화 주문의 실제 지원
- 사용자의 수동 주문 신청
- 전략 수익성 추천이나 보장
- 제품 승인 없이 기존 실행·출시 정책 변경
