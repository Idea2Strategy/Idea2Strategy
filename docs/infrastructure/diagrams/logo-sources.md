# 아키텍처 다이어그램 아이콘 출처

확인일: 2026-07-30

두 SVG는 저장소의 `icons` 디렉터리에 보관한 원본 아이콘을 참조한다. 네트워크 연결 없이도 재현할 수 있도록 인터넷에서 내려받은 원본과 출처를 함께 관리한다.

| 대상 | 출처 | 사용 자산 |
|---|---|---|
| AWS 서비스 | [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/) | 2026 Q2 공식 Icon Package의 Route 53, ACM, EC2, RDS, S3, ECR, Systems Manager, CloudWatch, VPC, EventBridge, Lambda 등 |
| GitHub | [Simple Icons의 GitHub](https://simpleicons.org/?q=github) | GitHub 심볼 |
| GitHub Actions | [Simple Icons의 GitHub Actions](https://simpleicons.org/?q=githubactions) | GitHub Actions 심볼 |
| Docker | [Simple Icons의 Docker](https://simpleicons.org/?q=docker) | Docker 심볼 |
| Terraform | [Simple Icons의 Terraform](https://simpleicons.org/?q=terraform) | Terraform 심볼 |
| Spring Boot | [Simple Icons의 Spring Boot](https://simpleicons.org/?q=springboot) | Spring Boot 심볼 |
| Redis | [Simple Icons의 Redis](https://simpleicons.org/?q=redis) | Redis 심볼 |
| Caddy | [Simple Icons의 Caddy](https://simpleicons.org/?q=caddy) | Caddy 심볼 |
| Apache Parquet | [Simple Icons의 Apache Parquet](https://simpleicons.org/?q=apacheparquet) | Apache Parquet 심볼 |
| Python | [Simple Icons의 Python](https://simpleicons.org/?q=python) | Python 심볼 |
| FastAPI | [Simple Icons의 FastAPI](https://simpleicons.org/?q=fastapi) | FastAPI 심볼 |

각 아이콘은 아키텍처 구성요소를 식별하는 목적으로만 사용한다. 브랜드명과 상표는 각 권리자에게 귀속된다.
