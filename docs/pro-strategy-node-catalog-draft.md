# Idea2Strategy Pro 전략 노드 카탈로그

상태: 검토용 초안
대상 화면: `/strategies/new/pro`
작성 기준일: 2026-07-28

## 1. 문서 목적

이 문서는 Pro 전략 그래프에서 제공할 노드를 8개 영역으로 나누고, 각 노드의 역할과 연결 요소를 정의한다.

- Pro는 프로그래밍 도구가 아니라 전문 투자자와 트레이더를 위한 전략 작성 도구다.
- 그래프는 왼쪽에서 오른쪽으로 흐르는 타입 기반 비순환 그래프를 사용한다.
- 편집 중에는 미완성 그래프를 허용하고, 출시 단계에서 전체 경로를 검증한다.
- 주문 노드는 실제 주문을 직접 전송하지 않고 서버 검사를 받을 `주문 후보`를 만든다.
- 사용자가 문자열 수식이나 코드를 직접 입력하는 기능은 제공하지 않는다.
- 첫 버전부터 롱·숏 전략을 모두 지원한다.

## 2. 등급과 구성 방식

| 구분 | 의미 |
| --- | --- |
| 핵심 | 기본 라이브러리에 노출하는 자주 사용하는 노드 |
| 고급 | 검색 또는 고급 탭에서 제공하는 전문 노드 |
| 매크로 | 여러 기본 노드를 투자자 친화적인 하나의 표현으로 묶은 노드 |
| 설정 | 독립 노드로 만들지 않고 해당 노드 안에서 선택하는 항목 |

매크로도 기본 노드와 같은 내부 실행 의미를 사용해야 한다. 사용자가 원하면 매크로의 내부 구성을 펼쳐 확인할 수 있어야 한다.

## 3. 포트 타입과 연결 색상

노드 헤더는 영역을 나타내고, 포트와 연결선의 색은 데이터 타입과 연결 가능 여부를 나타낸다. 색만으로 구별하지 않고 포트 모양과 타입명도 함께 표시한다.

| 포트 타입 | 의미 | 권장 색 | 보조 표현 |
| --- | --- | --- | --- |
| 거래 대상 | 종목 또는 종목군 | 청록 | 원형, `종목` |
| 가격 흐름 | 가격 시계열 | 파랑 | 사각형, `가격` |
| 거래 흐름 | 거래량·거래대금 시계열 | 하늘색 | 사각형, `거래` |
| 계산값 | 지표값·비율·금액·점수 | 보라 | 마름모, `값` |
| 조건 결과 | 현재 참·거짓 상태 | 노랑 | 삼각형, `조건` |
| 발생 신호 | 최초 충족·교차 등 사건 | 주황 | 삼각형, `신호` |
| 보유 상태 | 포지션·현금·손익·계좌 상태 | 남색 | 육각형, `보유` |
| 시장 상태 | 거래 세션·휴장·거래정지 상태 | 회청색 | 육각형, `시장` |
| 데이터 상태 | 정상·지연·누락 상태 | 민트 | 육각형, `데이터` |
| 주문 상태 | 대기·체결·취소·거절·만료 상태 | 올리브 | 육각형, `상태` |
| 배분값 | 예산·비중·수량 후보 | 분홍 | 마름모, `배분` |
| 주문 후보 | 아직 실행되지 않은 주문안 | 초록 | 육각형, `주문` |
| 위험 결과 | 주문 허용·축소·차단 | 빨강 | 방패형, `위험` |
| 흐름 | 조건 분기와 실행 순서 | 회색 | 화살표, `흐름` |

### 공통 연결 규칙

- 같은 타입끼리 직접 연결한다.
- 타입 변환이 필요하면 명시적인 계산·변환 노드를 사용한다.
- 서로 다른 시간축은 `시간축 맞추기`를 거쳐 연결한다.
- `조건 결과`와 `발생 신호`를 구분해 반복 주문을 방지한다.
- 선을 빈 캔버스에 놓으면 해당 타입을 입력받을 수 있는 노드만 검색 결과에 표시한다.
- 모든 주문 후보는 `위험검사`를 거쳐야 `주문 후보 완료`에 연결할 수 있다.

## 4. 거래 대상

종목을 선택하고, 조건에 맞게 거르고, 순위를 매겨 전략의 적용 대상을 만든다.

| ID | 노드 | 등급 | 입력 | 출력 | 주요 설정 |
| --- | --- | --- | --- | --- | --- |
| TAR-01 | 종목 직접 선택 | 핵심 | 없음 | 거래 대상 | 하나 또는 여러 종목 |
| TAR-02 | 종목 거르기 | 핵심 | 거래 대상, 계산값 | 거래 대상 | 가격·거래대금·시가총액·거래 상태 기준 |
| TAR-03 | 종목 순위 | 핵심 | 거래 대상, 계산값 | 거래 대상, 순위 점수 | 오름차순·내림차순, 상위·하위 N개 |
| TAR-04 | 종목군 합치기 | 고급 | 거래 대상 2개 이상 | 거래 대상 | 합집합·교집합·차집합 |
| TAR-05 | 기준 종목 연결 | 고급 | 거래 대상 | 거래 대상 | 지수·ETF·비교 종목 역할 지정 |
| TAR-06 | 각 종목에 적용 | 핵심 | 거래 대상, 흐름 | 종목별 흐름 | 종목별 독립 평가 |
| TAR-07 | 거래 가능 종목만 | 핵심 | 거래 대상, 시장 상태, 데이터 상태 | 거래 대상 | 거래정지·데이터 부족·주문 불가 제외 |

### 독립 노드로 만들지 않는 항목

- 거래소, 가격대, 시가총액, 거래량 필터는 각각 노드로 만들지 않고 `종목 거르기`의 조건 행으로 제공한다.
- 특정 종목 제외는 `종목군 합치기`의 차집합 또는 직접 선택 설정으로 처리한다.
- 제공 가능한 시장·기업 데이터가 확인되지 않은 필터는 선택지에 표시하지 않는다.

## 5. 가격·시장 정보

| MKT-04 | 가격 변화 | 핵심 | 가격 흐름 | 계산값 | 금액 변화·수익률·로그수익률, 비교 봉 |
| MKT-05 | VWAP | 핵심 | 거래 대상 | 가격 흐름 | 정규장·장전·장후 포함 범위 |

| MKT-08 | 호가·스프레드 | 고급 | 거래 대상 | 가격 흐름, 계산값 | 매수호가·매도호가·중간가·스프레드 |
| MKT-09 | 시장 상태 | 핵심 | 거래 대상 | 시장 상태, 조건 결과 | 장전·정규장·장후·휴장·거래정지 |
| MKT-10 | 데이터 상태 | 핵심 | 가격 흐름 또는 거래 흐름 | 데이터 상태, 조건 결과, 계산값 | 최신 여부·누락 여부·마지막 갱신 시각 |
| MKT-11 | 시계열 이동 | 고급 | 가격 흐름·거래 흐름·계산값 | 같은 입력 타입 | N봉 전 |
| MKT-12 | 시간축 맞추기 | 핵심 | 서로 다른 시간축의 시계열 | 정렬된 시계열 | 기준 시간축, 마지막 완성 봉, 누락값 처리 |

### 독립 노드로 만들지 않는 항목

- `이전 봉 데이터`는 개별 데이터마다 만들지 않고 `N봉 전` 설정 또는 `시계열 이동`으로 통합한다.
- `다중 시간대`는 독립 데이터가 아니라 각 노드의 시간축 설정과 `시간축 맞추기`로 표현한다.
- 평균 거래량은 `거래량 + 이동평균`, 거래량 변화율은 `거래량 + 변화율`로 구성한다.
- `현재가`라는 모호한 표현은 사용하지 않고 종가·최근 체결가·매수호가·매도호가를 구분한다.

### 제외 사항

- RSI·ADX 기준값은 지표 설정이 아니라 `값 비교`에서 입력한다.
- `지표 교차`는 지표 계산이 아니라 조건·타이밍에 둔다.
- 볼린저 밴드의 각 선을 별도 노드로 만들지 않는다.
- 문자열 또는 코드 형태의 사용자 직접 수식은 제공하지 않는다.
- 사칙연산 노드를 연결하더라도 반복문, 재귀, 외부 통신, 파일 접근, 임의값과 미래 데이터 참조는 허용하지 않는다.

### 공통 발동 설정

다음은 별도 노드가 아니라 조건 출력의 설정이다.

- 처음 만족한 순간
- 만족하는 동안 매번
- 불충족 후 다시 만족한 순간

기본값은 `처음 만족한 순간`이다. `만족하는 동안 매번`을 선택하면 반복 주문 위험을 경고한다.

### 제외 사항

- 독립 AND, OR, ELSE
- 조건 그룹 시작·종료
- 일반적인 프로그래밍 반복문
- 별도 `신호 확인` 노드

- 재진입 제한: 위험관리로 이동한다.
- 미체결 주문 처리: 주문 생명주기에 둔다.

- 미체결 취소, 포지션 축소와 청산은 사용자가 고급 설정으로 명시해야 한다.

- 손절·익절 노드는 직접 체결하지 않고 청산 주문 후보를 만든다.
- 숏 포지션에서는 손절·익절·트레일링의 가격 방향을 반대로 계산한다.
- 수량 축소나 청산 후보도 주문 가능 상태와 위험검사를 다시 통과한다.

## 12. 출시 전 그래프 검증

다음 항목 중 하나라도 충족하지 못하면 초안 저장은 가능하지만 전략 출시는 차단한다.

1. 거래 대상에서 주문 후보 완료까지 도달 가능한 경로가 하나 이상 있다.
2. 실행에 영향을 주는 고립 노드가 없다.
3. 필수 입력, 기간, 기준값, 단위와 적용 범위가 입력되어 있다.
4. 연결된 포트의 타입과 시간축이 호환된다.
5. 허용되지 않은 순환 연결이 없다.
6. 모든 조건 분기가 다음 조건, 주문, 흐름 합치기 또는 `아무것도 하지 않음`으로 끝난다.
7. 동시에 발생 가능한 주문 사이의 우선순위·전체 실행·예산 배분 규칙이 있다.
8. 모든 주문 후보에 방향, 수량, 유형, 가격과 유효기간이 결정되어 있다.
9. 모든 주문 후보가 자금 배분과 위험검사를 통과한다.
10. 주문 거절·부분 체결·미체결 대응이 필요한 흐름에 정의되어 있다.
11. 전략·봇·계좌 중 포지션과 자금의 적용 범위가 명확하다.
12. 숏 주문은 대차 가능 여부와 증거금을 검사한다.
13. 데이터 누락·지연, 거래정지와 주문 불가 상태의 대응이 정의되어 있다.
14. 완성 봉 신호가 같은 봉에서 소급 체결되지 않는다.
15. 지표 워밍업과 사용 가능한 과거 데이터 범위를 충족한다.

검토 화면은 각 실행 경로를 투자자 문장으로 풀어 보여주고, 확실하게 판정할 수 있는 범위에서 다음을 알린다.

- 완전히 같은 조건의 중복
- 항상 참 또는 항상 거짓인 조건
- 서로 모순되는 조건
- 도달할 수 없는 분기
- 주문으로 이어지지 않는 진입 신호
- 위험검사를 우회한 주문 경로

## 13. 초기 노출 권장 범위

### 핵심 라이브러리

약 35~45개 노드를 기본 목록에 노출한다.

- 직접 선택·필터·순위
- 가격·거래량·거래대금·VWAP·데이터 상태·시간축 맞추기
- SMA·EMA·RSI·MACD·볼린저 밴드·ATR
- 값 비교·범위·교차·조건 묶음·순서·연속 조건
- 시간 구간·요일·보유 기간
- 포지션 정보·손익·계좌 자금·숏 가능 상태
- 매수·매도·신규 숏·숏 청산 주문 후보
- 주문 규모·전략 예산·후보 주문 배분
- 고정 손절·익절·트레일링·ATR 손절
- 주요 손실·보유·노출 한도
- 데이터·시장 이상 대응과 위험검사

### 고급 라이브러리

검색 또는 고급 탭에서 제공한다.

- 종목군 집합 연산과 페어 기준 종목
- Anchored VWAP·호가·스프레드·시계열 이동
- 추가 지표와 기반 계산
- 상황별 실행·반대 조건·발생 횟수·일정 주기
- 계좌 노출·미체결 주문 노출
- 분할·연계 주문과 미체결 대응
- 목표 비중·리밸런싱
- 최대 낙폭·연속 손실·재진입·추가 진입 제한
- 취소·축소·청산을 포함한 위험 초과 행동

## 14. 구현 전 확인이 필요한 항목

다음은 노드 존재 여부가 아니라 실제 데이터·브로커·백테스트 지원 범위와 함께 확정해야 한다.

- 종목 필터에서 제공 가능한 시장·기업 데이터
- 지원 시간축과 보유 가능한 과거 데이터 길이
- 수정주가·비수정 가격과 기업행사 처리
- 각 지표의 공식, 평활 방식과 버전
- 호가·장전·장후 데이터 지원 범위
- 지정가·스톱·스톱 지정가·GTC·GTD의 실제 브로커 지원 범위
- 대차 가능 여부, 공매도 제한과 증거금 계산 방식
- 부분 체결·주문 거절·만료 상태 전이
- 수수료·슬리피지·호가 단위와 백테스트 체결 모델
- 각 기간·회차·종목 수·그래프 크기의 실제 상한
