# technology.need.object-storage

Large market data, high-volume backtest trade and replay-ledger details, position snapshots, calculation series, and immutable calculation evidence require content-addressed object or file storage linked from relational manifests. Backtest execution metadata, locked input references, monthly judgment summaries, compact performance summaries, and object integrity metadata remain relational. Exact storage service, columnar format, compression, and physical partitioning remain technology decisions.
